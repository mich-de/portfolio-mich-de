hello, world

Every programmer starts with hello, world. This diary starts the same way.

I write three kinds of things here, and each has its own branch:

  • thoughts: whatever is going through my head during the day
  • chronicles: stories that are happening right now
  • past: how things used to work, explained properly

[ did you know ]

hello, world became famous in 1978 with Kernighan and Ritchie's book on the C programming language, but Kernighan had already used it a few years earlier in a tutorial for the B language.

Why a Homemade Language

No WordPress, no off-the-shelf engine. Posts are plain text files written in a format called Nota, built from scratch for this website[1]. A small program turns them into static HTML pages: no code runs on the server, so there's nothing to exploit.

a typical blogthis diary
server-side codePHP and databasenone
JavaScriptquite a lot0 lines
security updatesconstantnone required

Fewer moving parts, fewer things that can break.

Photos and Audio

Images are added one per line. When they are adjacent, they automatically become a gallery; a click opens them at full size.

[ note ]

Before going online, metadata is removed from photos: GPS location, phone model, and capture date.

How It Is Written

The format is intentionally small:

nota# Section Title
A paragraph with *bold*, _italic_, and a [link](https://mdeangelis.me).
